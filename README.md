# Relanox documentation

[relanox.github.io](https://relanox.github.io/) hosts the documentation built from
[relanox/relanox](https://github.com/relanox/relanox/tree/master/docs).

The Documentation workflow checks the source repository every 30 minutes and
deploys only when its revision changes. Run the workflow manually to publish
immediately. It checks out the exact source commit and publishes with this
repository's GitHub Actions token; no cross-repository write credential is needed.

The source repository maintains redirects for old `/relanox/` URLs.
